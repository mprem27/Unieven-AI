# Same hybrid design, college/project palette

The existing cap, tassel, curved sides, calendar and centre design are retained.
Only colours/material finish were edited: college maroon #A91F23, academic navy
#27356A, light original Attendance sky blue #0EA5E9 accents and satin silver.
Smooth paint with medium controlled reflections, no added halo or orange.

Official palette reference: https://www.veltech.edu.in/wp-content/uploads/2026/01/veltech-logo-.png (downloaded from the university homepage on28October2026).
veltech-colour-reference.png is a source reference only; the full official wordmark
or outer seal was not added to the user's hybrid. Its existing centre content and
placement are retained. No institutional endorsement is claimed.

hybrid-3d-master.png is the colour-edit master. The static512 PNG and PWA/native
icons derive from it. Both introduction sequences use the complete static mark
with a short fade/settle, without independently rotating or deforming the centre.
The older five aligned PNG paths are regenerated for cached-client compatibility;
new introduction code does not assemble or animate these parts separately.
Original project reference remains at public/assets/project-original-logo.png.
