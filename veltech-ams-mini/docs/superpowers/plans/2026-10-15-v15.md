# V1.5 implementation plan

> For agentic workers: execute independent bounded modules with explicit file ownership, then review and test integration.

**Goal:** Deliver the requested web improvements as V1.5 ZIP, guide and verified public preview.
**Architecture:** Extend existing React/Vite, Node campus API and private FastAPI academic bridge. Keep official identity, social identity, private evidence and device storage separate.
**Tech stack:** Existing locked React, Node, Python and MongoDB stack; no new provider or native build needed.
**Spec:** ../specs/2026-10-15-v15.md

## Global constraints

- No real credentials or private records in source, ZIP or public preview.
- No invented AMS sections, unlimited free storage or anti-cheating guarantees.
- Windows PowerShell + Docker Desktop + Atlas, no Ubuntu requirement.

## Review focus

- Comments must reject edits at five minutes and edits by another account.
- Full-screen reels must retain feed position and comments after closing.
- Only faculty/admin may publish forms or export scoped responses; live capture requires fresh challenge and private ownership.
- Missing academic modules retain last good data with explicit source error/time.
- Device snapshots must exclude keys/sessions/private evidence and handle storage limits.
